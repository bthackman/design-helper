# Site search — [Project name]

*Used when the site is not yet chosen. Two stages; each ends with a user decision. If the site is already known, skip to Site-Details.*

## Stage 1 — zone scan
1. Selection criteria from client motives + brief (water, character, commute ceilings, sun, access...)
2. Candidate zones (3–5), each scored: access math (state units!), character, jurisdiction, honest caveats
3. Named trade-off: what the criteria make impossible, and the defensible reading
4. Verdict per zone: drill down / cut (cuts documented — they strengthen the final argument)

## Stage 2 — parcel drill-down
1. Verify zone land use via municipal open data (district codes, adjacency to park/water reserves)
2. Satellite review → candidate parcels/bands (link exact map-view URLs, don't embed screenshots)
3. Scorecard vs client motives; recommendation + runner-up
4. User selects → log decision with rejected alternatives → create `Site-Details_[address].md`
