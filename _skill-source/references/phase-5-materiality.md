# Phase 5 — Materiality

Output: `5_Materiality/Material-Palette.md` — 2–3 candidate palettes proposed as coherent arguments,
scored against the locked drivers, one locked with reasons; then a final palette organized by
system (envelope, structure, interior), each material justified by driver or precedent, with
performance/cost/carbon flags.

**Status note:** this is the tool's least-earned phase — it has never run against a real project,
so this reference is drafted from method, not from a failure this phase actually had. Expect the
first real run to surface gaps this doesn't cover yet, the way every other phase's reference was
sharpened by an actual mistake.

## Start from the thinking, not the swatch
Pull forward: material lessons from the precedent board, climate realities from the site facts,
budget constraints from the brief, and the locked drivers. Write these down before proposing
anything — a palette argued backward from a swatch you already liked is the failure mode this
phase is most exposed to, since unlike a citation or a geometry, "I like this material" has no
fetch-before-cite equivalent to catch it. Say so explicitly if a choice is taste rather than driver
work — `[proxy, unverified]` or similar, same convention as an invented client position.

## Sweep the library, pooled with fresh consideration
Check `Library/Materials/` (tagged by system, climate, cost tier) for materials already vetted —
on this practice's own past projects, or the starter set seeded 2026-08-28. Run that sweep
alongside, not before, fresh consideration of what this project specifically needs — same
correction the precedent phase made to its own vault-first rule (patch 8): a library reflects what
you've already used, so checking it *first* biases the palette toward repeating itself. Pool both,
and note explicitly if a candidate came from the library versus fresh — if that ratio climbs
project after project, the palette work is closing in on itself.

## Propose 2–3 genuinely different candidates
A palette is an argument, not a shopping list. "Heavy civic base, light warm upper body" and "one
material, inside and out, honestly aged" are two different arguments; three swatches of the same
argument are one candidate, not three (the same rule massing already applies to parti options).
For each candidate: envelope, structure, and interior materials, each with its own why — link to a
driver or a precedent card, not just "it looks right" — cost tier, and performance/carbon notes.

## Score against drivers, and test with value engineering
Score each candidate against the locked drivers the same way massing options do (a scorecard, not
a paragraph). Then stress it: **if value engineering cuts 10%, what goes first, and does the
argument survive losing it?** A palette that collapses under its cheapest material was never
actually a coherent argument — it was a shopping list wearing one. Which material in each candidate
is doing driver work, and which is just taste that happened to be defensible until the budget
moved?

## Lock, then stamp the final tables
State which candidate wins and why — the trade being made explicit, same as the massing lock. Only
after locking does the final palette-by-system table get filled in; it's the record, not the
working surface.

## Coherence check against earlier phases
Read the locked palette against the massing and site strategy: does the material logic reinforce
the parti (e.g. a heavy base where the building meets the ground), or fight it? Materials are the
last phase but they argue with every earlier one — a loop back to phase 3 here, on paper, is normal
and far cheaper than the same discovery in DD.

## Promote back to the library
At the phase gate, promote the locked palette's materials — the ones actually chosen, ideally after
a real build confirms they held up — into the matching `Library/Materials/` file, tagged by
climate and cost tier, the same way precedent cards only get promoted after fetch-before-cite
verification. This is how the starter library stops being drafted-and-unverified over time.

## Gate questions worth asking
If value engineering cuts 10%, which material goes first and does the palette survive it? Which
material is doing driver work, and which is just taste? What will this look like after ten
winters? Would the Studio Critic voice, if run, flag anything about maintenance burden or
code/climate compliance that this pass missed?
