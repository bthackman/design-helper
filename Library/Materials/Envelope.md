# Materials — Envelope

Starting library for the envelope system: cladding, glazing, roofing, insulation strategy. Tagged
by climate fit, cost tier, and durability/maintenance so a project can sweep this before proposing
palette candidates (phase 5) — same principle as the precedent phase's awards ladder: known-good
options compete on merit, they don't get invented fresh every project.

**These are drafted starting points, not verified specs.** [proxy, unverified] — general
architectural knowledge, not fetched from a manufacturer spec sheet or a built project. Verify
actual performance numbers, current pricing, and code compliance before citing any of this in a
real deliverable. Promote a *real* project's actual choice here once it's built and known to work,
the same way precedent cards only get promoted after fetch-before-cite verification.

**Climate of origin: cold-climate / freeze-thaw / heating-dominated (seeded 2026-08-28, no other
climate represented yet).** Every entry below assumes that context — triple-glazing called
"non-negotiable," freeze-thaw durability as the default test. A 2026-09-06 synthetic pilot run in a
hot/equatorial context found this set 0% usable there, not just biased toward one answer but
answering a question that project didn't have. Sweep this list on any project, but if the site's
climate isn't cold/freeze-thaw, treat every row as untested for that context rather than adapting a
cold-climate row by assumption — draft fresh candidates and promote the real ones back here once a
project actually earns them, the same way this file itself should have grown past one climate by now.

| Material | Climate fit | Cost tier | Durability / maintenance | Embodied carbon (relative) | Notes |
|---|---|---|---|---|---|
| Board-formed concrete | Excellent cold-climate; freeze-thaw proven | $$$ | Very high durability; near-zero maintenance | High (cement-heavy) | Reads heavy/civic; good "base" material against a lighter upper body |
| Standing-seam metal (steel or zinc) | Excellent; sheds snow, no freeze-thaw risk | $$–$$$ | High; occasional fastener/sealant checks | Moderate | Works as wall or roof; steel cheaper than zinc, zinc patinas |
| Cedar (rainscreen, unfinished/pre-weathered) | Good if detailed with a rainscreen gap; UV/moisture sensitive if not | $$–$$$ | Moderate; re-oil or let silver naturally, plan for board replacement | Low (renewable, low-processing) | The "warm upper body" counterpart to a heavy base; avoid ground contact |
| Fibre-cement panel/lap siding | Good; stable in freeze-thaw, low maintenance | $$ | High; occasional recaulking at joints | Moderate | Budget-conscious stand-in for wood look without the maintenance |
| Brick veneer | Good, well-proven regionally | $$–$$$ | Very high; virtually maintenance-free | Moderate–high (firing) | Reads civic/permanent; heavier foundation/detailing implications |
| Triple-glazed fibreglass or wood-clad-aluminum windows | Required-grade for -20°C design case | $$$ | High if properly flashed | Moderate (embodied in frame + glass) | Non-negotiable in this climate for any all-day room; don't value-engineer to double-glazed on a D3-driven project |
| Exterior mineral wool (continuous insulation) | Excellent; non-combustible, doesn't lose R-value when damp | $$ | High; protected once clad | Low–moderate | Pairs with any rainscreen cladding above; addresses thermal bridging that batt-only assemblies miss |
